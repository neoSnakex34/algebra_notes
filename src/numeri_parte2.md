# Aritmetica in \\( \mathbb{Z} \\) 
  
## divisione euclidea  
### def  
cfr. [Teorema 4.2](https://www.mat.uniroma2.it/~gavarini/page-web_files/mat-didat_data/dispense-ecc/note_di_D%27Andrea/Aritmetica.pdf)
\\[
  a, b \in \mathbb{Z} \text{ t.c. } b \neq 0 \implies \exists q, r \in \mathbb{Z}, a = qb + r, 0 \le r \lt |b|. 
\\]
\\( \space\space \square  \\)

## divisori
Introduciamo la definizione formale di divisore, accennato nella definizione di dominio di integrità.
### def 
Se possiamo scrivere un elemento \\( c = ab, a, b, c \in \mathbb{Z} \\), ovvero se dalla definizione precedente risulta \\( r = 0 \\), allora diciamo che \\( a \\) divide \\( b \\), e lo indichiamo con \\( a \mid b \\). Se tale numero non esiste allora diciamo che \\( a \\) non divide \\( b \\) e lo indichiamo con \\( a \nmid b \\). \\( \space\space \square  \\)
